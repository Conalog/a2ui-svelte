# Security

The renderer treats every message from an agent as untrusted; [docs/design.md](docs/design.md#9-security) describes how.

## Reporting a vulnerability

Report a vulnerability privately through the repository's "Report a vulnerability" button on GitHub (Security, then Advisories). Do not open a public issue or pull request for it.

Include the package version, the A2UI messages or component code that show the problem, and what an attacker gains. We confirm the report, agree on a fix and a disclosure date with you, and credit you in the advisory unless you prefer otherwise.

A vulnerability in `@a2ui/web_core` or in the shared basic catalog elements belongs to the official A2UI project; follow the reporting instructions of [a2ui-project/a2ui](https://github.com/a2ui-project/a2ui).
